Ballkickers is a fast, playful local multiplayer football game.

- 1v1: one controller drives two units, using both sticks and shoulders.
- 2v2 and 3v3: one unit per controller; bots fill empty places.
- Charge shots, dash tackles, keeper dives and heavy shot impacts.
- GameNight integration, controller profiles and automatic session setup.

Download **ballkickers-windows.zip**, extract it, and open **Ballkickers.exe**.
Keep the PCK beside the executable. No separate Godot install is needed.
The build uses the official Godot 4.5.2 runner and is unsigned.

GameNight's current host supports four controller seats. 3v3 fills remaining
places with bots there; the game adapter supports six seats when the host does.
